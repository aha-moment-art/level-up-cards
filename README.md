# Level Up vocabulary cards

Self-contained daily vocabulary cards embedded in the Level Up Notion learning calendar. Each page contains its own word data, styles, interaction code, and British and American pronunciation recordings.

Tap to flip. Swipe left for the previous word and right for the next word.

Pronunciation uses a native HTML audio player with MP3 Blob URLs created from the embedded recordings. Playback starts directly from the user's tap and uses the media player's actual progress. No external audio request is needed.
